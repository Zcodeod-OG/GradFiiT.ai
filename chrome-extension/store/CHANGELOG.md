# Changelog

All notable releases of the GradFiT browser extension for store packages.

## [1.0.0] - 2026-05-20

### Added

- Virtual try-on from product images on retailer sites
- Sidebar quick preview and Full Try-On link to gradfit.tech
- Closet-based style recommendations (glow + “Recommended for you”)
- Combo Studio (cross-site top + bottom)
- Affiliate Buy-this links after try-on
- Sign-in sync with gradfit.tech JWT
- Style highlights toggle in popup

### Store publishing

- Initial Chromium store submission package (Chrome, Edge, Opera, Brave)
