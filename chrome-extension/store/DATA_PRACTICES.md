# Data practices (Chrome Web Store privacy form)

Use this when completing **Privacy practices** in the Chrome Developer Dashboard. Adjust if your backend vendors change.

## Does your extension collect user data?

**Yes.**

## Data types collected

| Type | Collected | Purpose |
|------|-----------|---------|
| Authentication info | Yes | JWT after sign-in on gradfit.tech |
| Website content | Yes | Product images, URLs, titles/alt text on pages you visit |
| User activity | Yes | Try-on events, affiliate click logs |
| Personal communications | No | |
| Location | No | |
| Web history (browsing history list) | No | We do not upload a history feed; we process the current page when you use the extension |
| Financial/payment | No | |

## How data is used

- Provide virtual try-on and previews
- Authenticate API requests
- Style recommendations from your GradFiT closet
- Affiliate attribution when you use Buy-this links
- Service reliability and abuse prevention

## Is data sold to third parties?

**No.**

## Is data used for purposes unrelated to the single purpose?

**No** — only fashion try-on and related shopping assistance.

## Is data shared with third parties?

**Yes**, with service providers necessary to operate GradFiT:

- **GradFiT API** (https://gradfit-ai.onrender.com) — try-on, garments, auth
- **Cloud storage / AI providers** (via backend) — image processing
- **Affiliate networks** (only when you click Buy-this) — Amazon Associates, EarnKaro, CueLinks as configured
