**Testing GradFiT**

1. Install the extension and open https://gradfit.tech
2. Create an account or sign in (email/password or social login if enabled)
3. Upload a person photo in account settings if prompted for try-on
4. Open a fashion product page (for example https://www2.hm.com or any Shopify apparel store)
5. Hover the main product image — click **Try on**
6. Confirm the sidebar opens and a preview generates (may take 15–60 seconds on first request)
7. Optional: enable **Style highlights** in the extension popup after saving garments in the GradFiT closet

**Permissions**

Host access is required because users shop on many different domains. The extension only injects UI on pages with detectable product images.

**Account**

Reviewers may use a test account you provide, or self-register. API: https://gradfit-ai.onrender.com
