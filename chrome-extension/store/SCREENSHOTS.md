# Screenshots and promo assets

Capture manually after loading the production extension (store ZIP or signed build).

## Required sizes

| Store | Requirement |
|-------|-------------|
| Chrome Web Store | At least **1** screenshot, **1280×800** or **640×400** (JPEG/PNG, 24-bit) |
| Edge / Opera / Brave | Similar landscape screenshots recommended |

Upload up to **5** screenshots on Chrome.

## Optional promo images (Chrome)

| Asset | Size |
|-------|------|
| Small promo tile | 440×280 |
| Marquee promo | 1400×560 |

## Recommended scenes

1. **Product CTA** — Fashion product page with GradFiT “Try on” pill on hover (1280×800).
2. **Sidebar preview** — Sidebar open showing try-on result and Full Try-On / Save actions.
3. **Recommendation glow** — Product with blue brand glow and “Recommended for you” badge.
4. **Extension popup** — Popup signed in with user snapshot and style highlights toggle.
5. **Buy this** — Sidebar after try-on with Buy-this button and disclosure line.

## Capture tips

- Use a clean retailer (H&M, ASOS, or similar) with one product in view.
- Sign in at https://gradfit.tech first so the reviewer flow works.
- Hide personal bookmarks bar (Chrome guest profile helps).
- Use light mode for consistency with listing screenshots.
- Save as PNG; compress if over store size limits.

## File naming


Create the `screenshots/` folder when assets are ready (gitignore large binaries if needed).
